> 本文档只出设计规格（令牌 / 线框 / 排版规则 / 反 slop 检查点 / 选型建议），不含 HTML/CSS 实现代码。
> 文中 CSS 变量块与 mermaid 配置为规格表达形式，供实现者直接转写。
> 依据真实内容形态制定：10 节讲义（`01_学生版逐节讲义/*.md`），每节 = H1 + 引导 blockquote（建议时长 / 本节目标）+ 长段落 + 3 张 PNG 截图配图（alt 已含"图 N：说明"）+ 1 个 mermaid flowchart + H3 教学块（屏幕演示建议 / 本节跟做 / 本节小结）。

## 0. 共用基础约束（两套方向都适用）

### 0.1 站点形态与技术前提
- 纯静态、无构建：GitHub Pages 直接托管 `index.html` + `lesson-01.html … lesson-10.html`，所有样式收敛到一个 `tokens.css` + 一个 `site.css`，全部页面共享。
- 流量场景：微信分享 → 手机浏览器打开为主。**移动优先**，桌面为增强。
- 字体策略（关键决策）：**CJK 不加载网络字体**（全量中文字体数 MB，Pages 无 CDN 加速，移动 webview 不可控）。中文用系统字体栈，网络字体只覆盖拉丁字母与数字（体积 < 40KB），中文字形自动落到栈内系统中文字体。

### 0.2 共用结构令牌
```css

  --space-2: 0.5rem;   /* 8  */

  --space-8: 4rem;     /* 64 */
  --space-9: 6rem;     /* 96 */

  --text-lead: 1.125rem;    /* 18 重点卡描述/引导句 */
  --text-h3: 1.25rem;       /* 20（移动 18） */
  --text-h2: 1.5rem;        /* 24（移动 22） */
  --text-h1: 2rem;          /* 32（移动 28） */
  --text-display: 2.75rem;  /* 44（移动 30–32）仅首页 hero */

  /* 行高 */
  --lh-display: 1.2; --lh-h1: 1.3; --lh-h2: 1.35; --lh-h3: 1.4;
```

### 0.3 共用行为规则
1. `::selection` 必须定义（两套各自给色），禁默认蓝。
2. `:focus-visible` = 2px 实线强调色 outline + 2px offset，禁 `outline: none` 无替代。
3. 正文中文段落 `text-align: left`（两端对齐遇英文/URL 会产生字距河沟）。
4. 图片一律 `max-width:100%; height:auto; loading="lazy"`，写死 `width/height` 防 CLS。
5. mermaid 必须 `theme: 'base'` + 自定义 `themeVariables`（两套各自给值）。**mermaid 默认主题会注入淡紫 `#ECECFF` 节点，是全站最隐蔽的 AI-slop 来源。**
6. 代码高亮禁第三方默认主题（highlight.js default / prism okaidia 都带蓝紫），按两套各自的 4 色语法映射自定义。
7. 状态色（success/warning/error）永不单独依赖色相表意，必须配文字标签（如"注意""常见误区"）。
8. 无 emoji 徽章、无 🚀⚡✨✅ 类装饰符号；勾选/标记一律用 CSS 或排版符号（— · ▪ →）。

# 方向 A：极简学术系

## A-1. 设计意图

一句话定调：**"一册排版精良的油墨讲义"**——纸感暖白底、近黑墨色正文、单一黛蓝强调色，衬线标题建立书卷气，靠留白和字重节奏取胜。参考 Stripe docs 的克制与 Paul Graham 的"内容即设计"，但**必须比 PG 多一层完成度**（hover/focus/selection/卡片态齐全），否则就是"没做完"而不是"极简"。

## A-2. 设计令牌

```css
:root {
  /* ---- 色彩：纸 · 墨 · 黛蓝 ---- */
  --paper:        #FBFAF7;  /* 页面底（暖白纸感） */
  --surface:      #FFFFFF;  /* 卡片/图面 */
  --tint:         #F4F2ED;  /* 面板/代码块底 */

  /* 中性墨阶 7 档 */
  --ink-1: #1C1B1A;  /* 主文字，on paper ≈16:1 */
  --ink-2: #45423E;  /* 强调次级文字 */
  --ink-3: #5C5955;  /* 次级文字，on paper ≈6.7:1 */
  --ink-4: #6E6A63;  /* 图注/元信息，on paper ≈5.1:1（信息类灰字下限，勿再浅） */
  --ink-5: #8A867F;  /* 仅装饰/占位，禁承载信息（对比仅 3.5:1） */
  --line:        #E6E3DD;  /* 发丝边框 */
  --line-strong: #C9C5BC;  /* 强调边框/mermaid 节点描边 */

  /* 单一强调色：黛蓝（petrol，刻意远离 AI 蓝 #3B82F6 的明度与饱和度） */
  --accent:        #1F5566;  /* on paper ≈8.2:1；白字其上 ≈8.2:1 */
  --accent-strong: #173F4B;  /* hover */
  --accent-tint:   #E9F0F1;  /* 链接 hover 底、标签底 */
  --selection:     #D8E5E8;

  /* 语义色（仅用于带文字标签的状态块） */
  --success: #276A45; --success-tint: #E8F1EB;
  --warning: #8A5A00; --warning-tint: #F7EEDD;
  --error:   #B03527; --error-tint:   #F9E9E6;
  --info: var(--accent); --info-tint: var(--accent-tint);

  /* ---- 字体 ---- */
  --font-display: "Source Serif 4", "Noto Serif SC", "Songti SC", "STSong", "SimSun", serif;
  --font-body: -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC",
               "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif;
  --font-mono: ui-monospace, "SF Mono", "Cascadia Code", Menlo, Consolas, "Liberation Mono", monospace;

  /* 字重：只用 400 / 500 / 600。禁用 300（细 CJK = 廉价感） */
  --fw-regular: 400; --fw-medium: 500; --fw-semibold: 600;

  /* ---- 圆角：克制、偏锐利 ---- */
  --r-sm: 4px;  /* 行内代码、小标签 */
  --r-md: 6px;  /* 卡片、代码块 */
  --r-lg: 8px;  /* 面板、图 */

  /* ---- 阴影：仅 2 档，且只允许出现在卡片 hover ---- */
  --shadow-1: 0 1px 2px rgb(28 27 26 / 0.05);
  --shadow-2: 0 4px 12px rgb(28 27 26 / 0.08);
}
```

**网络字体加载（规格）**：仅加载 `Source Serif 4 (600,700)` + `Noto Serif SC (600,700)`，`display=swap`。Noto Serif SC 由 Google Fonts 按 unicode-range 切片，浏览器只下载页面实际用到的字形分片。正文与等宽字体零加载（系统栈）。

## A-5. 反 AI-slop 检查点（本方向最易翻车的 7 处）

1. **衬线回退灾难（最高危）**：若 Noto Serif SC 加载失败，Windows 用户看到 SimSun 假粗体标题 → 瞬间变成 2005 年网页。对策：确认 `<link>` 生效 + `display=swap`；**必须在 Windows Chrome 真机截图验收标题**。若不可接受，降级预案：标题也用系统黑体栈，改以"字重 600 vs 400 + 字号差 ≥8px"维持层级。
2. **"未完成感"**：极简与"Pandoc 默认导出"只差一层。验收时必须看到：链接 hover、focus 环、自定义 selection、卡片 hover、图片边框——缺一项即判定"没做完"。
3. **mermaid 默认主题**：默认节点淡紫 #ECECFF 是全站唯一紫色来源，必须按 A-4 的 themeVariables 覆盖。
4. **代码高亮主题**：highlight.js/prism 默认主题蓝紫泛滥，按 A-4 的 4 色映射自定义。
5. **灰字层级塌陷**：caption 若用 --ink-5(#8A867F) 仅 3.5:1 不达标。信息类灰字锁定 --ink-4(#6E6A63) 为下限。
6. **强调色预算**：每屏 --accent 出现 ≤3 类元素（链接 / eyebrow / 课程编号）。出现在大面积底色、按钮全屏填充 = 失去克制，打回。
7. **emoji 钩子与徽章**：本节目标列表禁 ✅，CTA 禁 🚀；用排版符号（— · →）。

# 方向 B：教育温暖系

## B-1. 设计意图

一句话定调：**"一位有耐心的助教，把讲义摊在奶油色桌面上"**——奶油底、咖啡墨色、陶土点缀，圆润但不低幼。参考 Notion 课程页的干净亲切，**明确拒绝 Duolingo 的低幼化**（无弹跳动画、无绿鹦鹉配色、无 emoji 徽章），目标用户是成年零基础学员，温暖来自色彩与圆角，专业感来自层级纪律。

```css
  --amber-soft:   #FBEEDC;  /* 重点卡底 */
  --amber:        #D9A441;  /* 仅装饰（H2 下短尺/高亮），禁作文字色 */
  --amber-hl:     #F9E9C4;  /* 文字高亮 marker 底 */

  /* 中性咖啡阶 7 档 */
  --coffee-1: #33291F;  /* 主文字，on cream ≈13:1 */
  --coffee-2: #5A4E42;  /* 强调次级，≈7.5:1 */
  --coffee-3: #6E6156;  /* 次级文字，≈5.6:1 */
  --coffee-4: #7D6F61;  /* 图注/元信息下限，≈4.5:1 */
  --coffee-5: #A08F7D;  /* 仅装饰，禁承载信息 */
  --line:        #EDE3D3;

  --accent-soft:   #F8E8DB;  /* 面板底/hover 底 */
  --selection:     #F3E2BC;

  /* 语义色（暖调协调版；error 与陶土近色，必须配文字标签） */
  --success: #4F7340; --success-tint: #EBF1E4;
  --warning: #8F6408; --warning-tint: #F9EFD8;
  --error:   #A83A32; --error-tint:   #F8E7E3;

               "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif;
  --font-mono: ui-monospace, "SF Mono", "Cascadia Code", Menlo, Consolas, "Liberation Mono", monospace;

  /* 字重：400 正文 / 500 元信息 / 700 标题与强调。Nunito 拉丁标题可用 800，CJK 黑体标题用 700 */
  --fw-regular: 400; --fw-medium: 500; --fw-bold: 700; --fw-heavy: 800;

  /* ---- 圆角：圆润有上限 ---- */
  --r-sm: 6px;   /* 行内代码 */
  --r-md: 10px;  /* 代码块、引用块 */
  --r-lg: 16px;  /* 卡片、面板、图（上限，再大即低幼） */
  --r-pill: 999px; /* 仅元信息小 chip 与 H2 装饰短尺 */

  /* ---- 阴影：仅 2 档，暖棕着色，只允许卡片 hover ---- */

  --shadow-2: 0 8px 20px rgb(74 52 30 / 0.10);
}
```

**网络字体加载（规格）**：仅加载 `Nunito (700,800)`，`display=swap`。中文标题依赖 PingFang/雅黑加粗——温暖感由色彩、圆角、间距承担，这是刻意的务实决策：中文圆体网络字体（如站酷快乐体）体积大且低幼，与本课程"成熟亲切"定位冲突。

## B-5. 反 AI-slop 检查点（本方向最易翻车的 7 处）

1. **暖色糊成一片（最高危）**：奶油底 + 米卡 + 棕边 → 零层级。铁律：表面只允许两层（--cream 底 / --surface 卡），边框只有 --line 一档（hover 才用 --line-strong）；卡片靠边框定义，不靠投影。
2. **陶土滥用成"番茄炒蛋"**：标题保持 --coffee-1 不染色；--accent-strong 只给链接/CTA/编号 chip/eyebrow，每屏 ≤3 类元素；--accent(#C25E3C) 因对比不足禁作正文级文字，文字一律走 --accent-strong。
3. **圆润滑向低幼**：圆角 ≤16px、Nunito ≤800、无弹跳/回弹动画、无 emoji、无 Duolingo 式插画徽章。破例只允许：编号 chip 与 pill chip 的几何圆润。
4. **error 与陶土撞色**：--error(#A83A32) 与 --accent-strong 近色，所有状态块必须带文字标签（"注意""常见误区"），禁纯靠颜色表意。
5. **截图白底像补丁**：PNG 截图白底浮在奶油页面上会显脏，必须用 --figure-surface 纯白面 + 1px --line + 圆角包裹。
6. **假数据 slop**：禁"10,000+ 学员已学""99% 好评"徽章（除非真实可溯源）；学员评价 quote 必须有真实出处，否则整个模块不放。
7. **琥珀装饰失控**：--amber 只出现在 H2 短尺与偶尔的 strong 高亮，出现在背景/按钮/图标 = 打回。

# 5. 两套对比与选型建议

| 维度 | A 极简学术系 | B 教育温暖系 |
|---|---|---|
| 0.5 秒第一印象 | 冷静、专业、"像官方文档" | 亲切、有耐心、"像有人在教我" |
| 目标受众契合（零基础成人 + 微信分享手机端进入） | 中：专业但略有距离感 | **高：直接对症"怕难"的第一流失点** |
| 信任构建路径 | 严谨感 → "这课很靠谱" | 陪伴感 → "这课我能学会" |
| 字体加载风险 | **高**：Noto Serif SC 在移动 webview 有 FOUT，Windows 回退 SimSun 翻车 | **零**：Nunito 只覆盖拉丁，中文全系统栈 |
| 执行难度 | 低（元素少、无色彩管理负担） | 中（暖色层级需要纪律，见 B-5-1/2） |
| 跑偏形态 | 跑偏成"没做完的 Pandoc 导出" | 跑偏成"低幼番茄炒蛋" |
| 截图 PNG 兼容 | 好 | 好（需白面容器纪律） |
| 转化链路（8.8 元 → 进阶课） | 间接：靠专业信任，CTA 克制 | 直接：亲和力降低付费心理门槛，CTA 可放实心按钮 |
| 维护成本 | 极低 | 低 |

**明确推荐：选 B（教育温暖系），执行时套用 A 的克制纪律——"温暖的皮，学术的骨"。**

理由：
1. **流量场景决定**：8.8 元引流课的入口是微信分享 → 手机浏览器，用户 3 秒内凭"亲切、不难、看得下去"决定留不留。B 的暖调直接服务这个判断；A 的冷静专业是给"主动来找文档的开发者"的。
2. **受众决定**：零基础成人学员的第一心理障碍是"我学不会"，温暖调性 + 圆润亲和是第一解法；学术冷感会放大距离。
3. **技术风险决定**：A 的命脉是衬线中文字体，而这恰恰是 Pages + 移动 webview 上最不可控的一环；B 的中文全走系统栈，渲染零风险。
4. **转化决定**：B 允许 CTA 用实心陶土按钮（A 的克制语境下只能放文字链接），对"引流 → 进阶课"的转化路径更直接。
5. **但 B 必须借用 A 的纪律**：强调色预算（每屏 ≤3 类）、状态色必配文字标签、卡片靠边框不靠投影、禁 emoji 徽章——没有这些，B 会滑向低幼。

若未来品牌转向开发者人群、做长文 SEO 博客或付费专业课，再切 A 不迟——两套令牌语义命名一致（--accent/--ink vs --coffee 角色一一对应），切换成本就是换一个令牌文件。
