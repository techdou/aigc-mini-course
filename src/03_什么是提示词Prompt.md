# 第 3 节：什么是提示词 Prompt

> 建议时长：12 分钟  
> 本节目标：让学生学会把模糊想法说清楚，能立刻写出可用 Prompt。

很多人用 AI 效果一般，不是因为模型太差，而是因为自己给出去的任务太模糊。你对人说话都需要把意思讲清楚，对 AI 当然也一样。所以 Prompt 不是神秘咒语，也不是“越长越高级”的一段话。Prompt 本质上就是任务表达，是你交给 AI 的一份清楚说明书。

在课堂上，我最喜欢用一句很简单的话来解释 Prompt：**Prompt 不是让 AI 猜你的心思，而是让 AI 明白你的心思。**

![图 1：Prompt 五要素卡——背景、目标、对象、要求、输出](../03_实践测试案例/assets/lesson03/01_Prompt五要素卡.png)


为了让初学者马上上手，我们把 Prompt 拆成五个最容易记住的部分。先说背景，让 AI 知道你现在是什么场景；再说目标，让 AI 明白你要完成什么；接着说对象，也就是内容是给谁看的；然后说要求，包括风格、限制、必须保留的内容；最后说输出，让它知道你最终想要的是什么格式。

这五部分一旦完整起来，你会发现，原本“模糊的一句话”就开始长出可执行的边界。举个最简单的例子，如果你只说“帮我做个英语网页”，模型其实只能大概猜；可如果你说“为小学三年级学生制作一个单文件动物英语学习网页，包含五个单词、中文释义、点击发音按钮和选择题小游戏，页面要适合电脑和手机浏览器，最终输出一个可直接打开的 HTML 文件”，那么 AI 的工作方向就立刻清晰了。

```mermaid

    A[模糊需求] --> B[补全背景]
    B --> C[明确对象与目标]
    C --> D[加入要求与限制]
    D --> E[明确最终输出]
    E --> F[得到更稳定结果]
```

![图 2：从模糊指令到结构化 Prompt 的前后对比](../03_实践测试案例/assets/lesson03/02_模糊到清晰对比图.png)


到这里，请大家一定要有一个新的判断标准：好 Prompt 不一定长，但一定清楚。它不追求华丽，而追求可执行。很多同学刚开始会紧张，觉得自己不会写 Prompt。其实只要你能把需求说给一个认真负责的助理听明白，你就已经会写 Prompt 了。

为了让你真正把这件事做出来，我们现在把刚才的五要素落到一个可以直接复用的课堂模板上。你可以这样写：我现在要做什么，给谁用，已经有什么材料，必须满足哪些要求，最后请输出什么。这个模板看上去很朴素，但它是最适合新手稳定起步的方式。

为了让你更直观地感受到"模糊"和"清晰"之间的差距，下面我们做几组真实对照。每一组都是同一个任务，左边是大家最容易随手写出来的模糊版本，右边是按五要素补全之后的清晰版本。你可以自己先判断一下：哪一条交给 AI，结果会更稳。

**对照一：写一段课程文案**

- 模糊版：`帮我写个课程介绍。`
- 清晰版：`我要给一套叫"豆懂AI动物英语微课"的小课程写一段介绍。受众是 6 到 9 岁孩子的家长，他们担心孩子英语启蒙太枯燥。课程主打用 AI 生成动物图片和互动网页帮孩子学单词。请用 80 到 120 字，语气温暖、接地气，不要堆专业词，结尾留一个温柔的引导，让家长愿意点进去看。`

为什么清晰版更好？因为它补上了对象（家长）、痛点（怕枯燥）、卖点（AI 动物图 + 互动）、风格（温暖接地气）、字数（80-120）和输出意图（结尾引导）。模糊版只能让 AI 猜你想要什么风格、写给谁，结果十有八九又长又空。

**对照二：做一张课程主视觉**

- 模糊版：`帮我画一张课程海报。`
- 清晰版：`请生成一张面向小学生的动物英语微课主视觉。画面中心是一只可爱的小猫和一条小鱼并排站着，背景是明亮的浅色教室，整体走儿童绘本的扁平矢量风格，配色温暖明亮，主体居中、构图干净，画面里不要出现任何文字和字母。输出 1024×1024 的图片。`

模糊版最大的问题是 AI 不知道画什么、什么风格、给谁看，于是经常给你一张"什么都像又什么都不像"的图。清晰版把主体、场景、风格、约束（无文字）和尺寸都说清楚了，AI 出图就会稳定很多。

**对照三：整理一个文件夹**

- 模糊版：`帮我把这些文件整理一下。`
- 清晰版：`我要整理一个课程素材文件夹，里面有 9 个文件，混着 .docx、.txt、.csv、.png。请先只读分析，不要移动、改名或删除；按"课程讲义/宣传素材/数据/待确认"四类给出分类建议；对可能重复的文件（比如两份都叫"最终版"的文档）单独标记；最后给我一份 CSV 清单，记录每个文件的原名、归类和你的判断依据。`

模糊版连"整理"是只读分析还是直接动手都没说清，AI 要么不敢动、要么乱动，都很危险。清晰版明确了范围（只读先行）、规则（四类分类）、风险处理（重复文件标记）和输出格式（CSV），这才是让 Agent 靠谱干活的样子。

如果你把这三组对照放在一起看，会发现一个共同规律：**模糊 Prompt 缺的不是字数，而是边界。** 一旦你说清楚对象、目标、约束和输出，AI 就从"猜你心思"变成"按说明书办事"。这就是新手最该练的能力。

### 屏幕演示建议

这一节适合做一个很短但非常直观的对比实验。先输入一句模糊 Prompt，例如“帮我做一个英语学习网页”；展示模型给出的含糊结果。然后再输入结构化版本，让学生看到结果明显更可控。演示的重点不是追求最终网页一次生成成功，而是让学生看懂：表达越清楚，结果越稳定。

### 本节跟做

请每位学生把第一节写下的“真实任务”重新整理成一条 Prompt。你不必追求写得华丽，只要把背景、目标、对象、要求和输出说清楚即可。完成之后，可以互相交换着看一眼，判断一下：这条 Prompt 能不能让另一个人也清楚知道任务是什么？如果能，基本就已经合格了。

### 本节小结

这一节最重要的收获，不是记住 Prompt 这个英文词，而是学会一种表达方式：**当你越能把任务讲清楚，AI 就越像一个靠谱的协作对象。** 下一节我们要继续往前走，看看为什么有的 AI 只能“说”，有的 AI 却能“做”，也就是 LLM 和 Agent 的区别。
